# 🌸 Classificador de Espécies com Machine Learning (Python)

> Projeto desenvolvido para demonstrar fundamentos de Inteligência Artificial e Ciência de Dados utilizando o clássico dataset **Iris**, aplicando divisão de bases, treinamento e avaliação de modelo preditivo.

---

### ⚙️ O que o projeto faz?
- **Análise Exploratória:** Organiza os dados em um DataFrame utilizando a biblioteca **Pandas**.
- **Treinamento de Modelo:** Utiliza o algoritmo KNN (*K-Nearest Neighbors*) da biblioteca **Scikit-Learn** para classificar espécies de flores com base em medidas físicas.
- **Avaliação de Desempenho:** Calcula a taxa de acurácia (precisão) das previsões do modelo.

---

### 🚀 Como Executar
Você pode rodar este projeto diretamente no navegador sem precisar instalar nada na sua máquina, abrindo o código no **Google Colab**.

---

### 🛠️ Tecnologias Utilizadas
- **Python**
- **Pandas** (Manipulação de dados)
- **Scikit-Learn** (Algoritmos de Machine Learning)
- **Google Colab** (Ambiente de desenvolvimento)
